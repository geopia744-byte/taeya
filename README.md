# 후킹 공장

해외 인스타그램 게시물 캡쳐를 넣으면, **한국어 · 日本語 · English** 각 문화에 맞는
후킹 제목과 캡션·해시태그를 새로 써서 이미지에 얹어주는 도구.

바로 업로드할 수 있는 상태로 PC 폴더에 저장된다.

## 이건 번역기가 아니다

```
CHILD R*PIST SHOT D3AD MOMENTS AFTER BEING RELEASED FROM PRISON
        │
        ├─ 🇰🇷  출소 직후 총격 사망 / 그를 기다린 건 자유가 아니었다   (감성적 반전)
        └─ 🇯🇵  出所から24時間で射殺 / 法に代わる「復讐」の正義        (사회적 논쟁)
```

원문에 없는 문장을 만든다. 같은 사건이라도 언어권마다 먹히는 후킹 포인트가 다르기
때문이다. 자세한 원리는 [docs/SPEC.md](docs/SPEC.md).

## 쓰는 법

### 1. 준비 (처음 한 번만)

```bash
pip install anthropic
```

### 2. 실행

```bash
python app.py
```

브라우저가 저절로 열린다. 끄려면 실행한 창에서 `Ctrl+C`.

### 3. API 키 넣기 (처음 한 번만)

화면 우측 상단 **설정** → Anthropic API 키를 넣고 저장.
키는 `config.json`에 저장되며, 이 파일은 git에 올라가지 않는다.

키가 없다면 [console.anthropic.com](https://console.anthropic.com) 에서 만들 수 있다.

### 4. 만들기

1. 캡쳐 이미지를 화면에 **끌어다 놓는다** (또는 왼쪽에서 파일·폴더 선택)
2. 언어를 고르고, 원하면 콘셉트를 적는다 — 예: `20대 타겟, 감성적인 톤`
3. **이미지 변환** 을 누른다
4. 마음에 안 드는 카드는 **다시 뽑기**, 본문은 직접 고쳐도 된다
5. **PC 폴더에 저장**

한 번에 20장 정도가 가장 쾌적하다.

## 결과물

```
출력/
└── 20260827_1430_ko/
    ├── 01_멕시코에 나타난 현실판 배트맨.png    ← 제목이 박힌 이미지
    ├── 01_멕시코에 나타난 현실판 배트맨.txt    ← 캡션 + 해시태그
    ├── 02_탈출한 벨루가의 기적.png
    └── 02_탈출한 벨루가의 기적.txt
```

이미지를 올리고, 같은 이름의 `.txt`를 열어 캡션에 붙여넣으면 끝.

저장 폴더는 **설정**에서 바꿀 수 있다.

## 기능

| | |
|---|---|
| 언어 | 한국어 · 日本語 · English |
| 입력 | 끌어다 놓기 · 파일 선택 · 폴더 통째로 |
| 자동 처리 | 인스타 UI(하트·댓글·캡션 칸) 잘라내고 사진만 남김 · 끌 수 있음 |
| 글자 | 위치(위·중간·아래) · 크기 조절 |
| 로고 | 이미지 업로드 · 위치(왼쪽·중간·오른쪽) · 크기 |
| 편집 | 카드별 다시 뽑기 · 본문 직접 수정 |
| 내보내기 | PC 폴더 저장 · 개별 이미지 · 전체 ZIP |

## 원본 툴에서 고친 것

**한글 줄바꿈이 단어를 쪼개던 문제.** 참고한 툴은 `자유가 아니` / `었다` 처럼
어절 중간에서 끊었다. 여기서는 AI가 준 의미 단위 줄을 그대로 지키되, 폭이 넘치면
줄을 늘리는 대신 **글자 크기를 줄인다.** 그래도 안 들어갈 때만 어절 단위로
다시 나누고, 단어는 어떤 경우에도 쪼개지 않는다.

## 알려진 한계

**흰 배경 위에 피사체만 있는 사진**(제품 사진 등)은 자동 잘라내기가 여백을 UI로
오해해 피사체만 남길 수 있다. 뉴스 캡쳐에서는 거의 없는 경우이고, 그럴 때는
왼쪽 패널의 **인스타 화면 자동으로 잘라내기** 를 끄면 원본 그대로 쓴다.

## 유의사항

원본 게시물의 사진은 해외 계정의 저작물이다. 실제 운영 시에는 출처 표기나
사용 허락을 챙기는 편이 안전하다.
