# 후킹 공장

해외 인스타그램 게시물 캡쳐를 넣으면, **한국어 · 日本語 · English** 각 문화에 맞는
후킹 제목과 캡션·해시태그를 새로 써서 이미지에 얹어주는 도구.

바로 업로드할 수 있는 상태로 PC 폴더에 저장된다.

## 이건 번역기가 아니다

```
CHILD R*PIST SHOT D3AD MOMENTS AFTER BEING RELEASED FROM PRISON
        │
        ├─ 🇰🇷  출소 직후 총격 사망 / 그를 기다린 건 자유가 아니었다   (감성적 반전)
        └─ 🇯🇵  出所から24時間で射殺 / 法に代わる「復讐」の正義        (사회적 논쟁)
```

원문에 없는 문장을 만든다. 같은 사건이라도 언어권마다 먹히는 후킹 포인트가 다르기
때문이다. 자세한 원리는 [docs/SPEC.md](docs/SPEC.md).

## 쓰는 법

### 1. 준비 (처음 한 번만)

```bash
pip install anthropic
```

### 2. 실행

```bash
python app.py
```

브라우저가 저절로 열린다. 끄려면 실행한 창에서 `Ctrl+C`.

### 3. API 키 넣기 (처음 한 번만)

화면 **왼쪽 위 설정** → 키를 넣고 저장.

키는 **계정 폴더**(`~/.hooking-factory/config.json`, 윈도우는
`C:\Users\내이름\.hooking-factory\config.json`)에 저장된다. 프로그램 폴더가
아니라 계정 폴더에 두는 이유는, 새 버전을 다른 폴더에 풀어도 키를 다시 넣지
않아도 되게 하기 위해서다. 예전 버전의 `config.json` 이 프로그램 폴더에 있으면
처음 실행할 때 옮겨온다.

| 키 | 하는 일 | 필수 |
|---|---|---|
| **Anthropic** | 후킹 제목·캡션·해시태그를 쓴다 | ✅ |
| **Gemini** | 사진에 박힌 원본 영어를 지운다 | 선택 |

- Anthropic 키: [console.anthropic.com](https://console.anthropic.com)
- Gemini 키: [aistudio.google.com](https://aistudio.google.com)

Gemini 키가 없어도 동작한다. 대신 원본 영어를 **지우지 않고 덮는다.**

### 4. 만들기

1. 캡쳐 이미지를 화면에 **끌어다 놓는다** (또는 왼쪽에서 파일·폴더 선택)
2. 언어를 고르고, 원하면 콘셉트를 적는다 — 예: `20대 타겟, 감성적인 톤`
3. **이미지 변환** 을 누른다
4. 마음에 안 드는 카드는 **다시 뽑기**, 본문은 직접 고쳐도 된다
5. **PC 폴더에 저장**

한 번에 20장 정도가 가장 쾌적하다.

## 결과물

```
출력/
└── 20260827_1430_ko/
    ├── 01_멕시코에 나타난 현실판 배트맨.png    ← 제목이 박힌 이미지
    ├── 01_멕시코에 나타난 현실판 배트맨.txt    ← 캡션 + 해시태그
    ├── 02_탈출한 벨루가의 기적.png
    └── 02_탈출한 벨루가의 기적.txt
```

이미지를 올리고, 같은 이름의 `.txt`를 열어 캡션에 붙여넣으면 끝.

저장 폴더는 **설정**에서 바꿀 수 있다.

## 기능

| | |
|---|---|
| 언어 | 한국어 · 日本語 · English |
| 입력 | 끌어다 놓기 · 파일 선택 · 폴더 통째로 |
| 자동 처리 | 인스타 UI(하트·댓글·캡션 칸) 잘라내고 사진만 남김 · 끌 수 있음 |
| 글자 | 위치(위·중간·아래) · 크기 조절 |
| 로고 | 이미지 업로드 · 위치(왼쪽·중간·오른쪽) · 크기 |
| 편집 | 카드별 다시 뽑기 · 본문 직접 수정 |
| 내보내기 | PC 폴더 저장 · 개별 이미지 · 전체 ZIP |

## 원본 툴에서 고친 것

**한글 줄바꿈이 단어를 쪼개던 문제.** 참고한 툴은 `자유가 아니` / `었다` 처럼
어절 중간에서 끊었다. 여기서는 AI가 준 의미 단위 줄을 그대로 지키되, 폭이 넘치면
줄을 늘리는 대신 **글자 크기를 줄인다.** 그래도 안 들어갈 때만 어절 단위로
다시 나누고, 단어는 어떤 경우에도 쪼개지 않는다.

## 사진 처리 — 세 가지 중 고른다

왼쪽 패널의 **사진 처리** 에서 고른다.

**그대로 두기** (무료) — 사진을 건드리지 않는다. 영어가 있던 범위를 불투명하게
덮어 가린다. 그만큼 사진이 가려지지만 비용이 들지 않는다.

**✂ 글자만 지우기** (Gemini 키 필요) — 박힌 영어를 지우고 그 자리를 주변 장면에
맞게 채운다. 원본 사진이 온전히 남는다.

**✨ 사진 새로 만들기** (Gemini 키 필요) — 인물·동물의 생김새는 그대로 두고
장면을 새로 만든다. 원본 사진을 쓰지 않으므로 글자가 남을 일이 없고, 남의
사진을 그대로 쓰지도 않는다. 참고한 원본 툴이 쓰던 방식이다.

사건 설명(원문·제목·본문)을 이미지 모델에 함께 넘기므로, 새로 만든 장면이
이야기에 맞는다.

지우기에 실패해도(정책 차단, 한도 초과 등) 카피는 그대로 남고 덮기로 이어간다.

### 속도

이미지 생성은 **분당 허용 횟수가 적다.** 그래서 카피는 여러 장을 동시에 쓰고,
글자 지우기는 **한 장씩 차례로** 보낸다. 한도에 걸리면 20초 → 45초 → 90초로
기다렸다 다시 시도한다.

무료 한도는 매우 적으므로, 20장씩 돌리려면 Google AI Studio 에서 결제를
설정해 한도를 올리는 편이 낫다. 월 지출 한도를 함께 걸어두면 안전하다.

**새로 만든 사진은 AI가 그린 것이다.** 실제 사건 현장 사진이 아니므로, 뉴스처럼
보이는 계정에서 쓸 때는 그 점을 밝히는 편이 안전하다.

> 워터마크·로고 제거는 요청하지 않는다. 출처 표시를 지우는 요청으로 분류되어
> 정책상 차단되고, 그러면 한 장도 처리하지 못한다. 구석의 워터마크는 로고
> 기능으로 덮으면 된다.

## 처리 순서

```
① 캡쳐에서 인스타 UI 잘라내기
② Claude — 후킹 제목·본문·해시태그 (원본 캡쳐 전체를 보고 쓴다)
③ Gemini — 원본 영어 지우기 / 사진 새로 만들기
④ 깨끗해진 사진에 한국어 얹기          ← 반드시 ③ 뒤
```

**④는 ③ 뒤에 온다.** 지워지기 전 사진에 한국어를 박아두면 지워졌는지 아닌지
눈으로 확인할 수 없다. 사진 처리가 끝나기 전까지 제목을 얹지 않는다.

## 사진 모델

설정에서 고를 수 있다. 비워두면 쓸 수 있는 것 중 가장 좋은 것을 자동으로 쓴다.

**한 모델이 막히면 곧장 다음 모델로 넘어간다.** 붐비는 모델을 붙잡고 기다리느니
다른 모델로 가는 편이 훨씬 빠르기 때문이다. 3개를 한 번씩 훑어 전부 막혔을
때에만 기다렸다 다시 돈다. 설정에서 모델을 직접 고르면 그것만 쓴다.

이름에 **`preview`** 가 붙은 모델은 구글이 서버를 조금만 열어둬서 늘 붐빈다.
성능이 좋아도 매번 막히면 쓸모가 없으므로 정식 출시본을 먼저 쓴다.

`lite` 모델은 값이 싸지만 **사진 편집을 제대로 못 하고 받은 사진을 그대로
돌려주는 일이 있다.** 그러면 영어가 남은 채로 "지웠다"고 표시되어 결과물이
망가지므로, 자동 선택에서는 맨 뒤로 보낸다. 돌려받은 사진이 보낸 것과 사실상
같으면 성공으로 처리하지 않고 그렇게 알린다.

## 알려진 한계

**흰 배경 위에 피사체만 있는 사진**(제품 사진 등)은 자동 잘라내기가 여백을 UI로
오해해 피사체만 남길 수 있다. 뉴스 캡쳐에서는 거의 없는 경우이고, 그럴 때는
왼쪽 패널의 **인스타 화면 자동으로 잘라내기** 를 끄면 원본 그대로 쓴다.

## 유의사항

원본 게시물의 사진은 해외 계정의 저작물이다. 실제 운영 시에는 출처 표기나
사용 허락을 챙기는 편이 안전하다.
