# taeya

**다국어 리포스팅 공장** — 해외 인스타 게시물 캡쳐를 넣으면, 한/일/영 각 문화에 맞는
후킹 제목과 캡션·해시태그를 새로 써서 얹어 바로 업로드 가능한 게시물로 뽑아주는 툴.

## 현재 상태

📋 **기획 단계** — 명세 정리 완료, 구현 착수 전

- [기획 명세서 (docs/SPEC.md)](docs/SPEC.md) — 유튜브 영상 캡쳐 8장을 역분석해 정리한 전체 명세

## 핵심 개념

이 툴의 엔진은 **번역기가 아니라 카피라이터**다.

```
CHILD R*PIST SHOT D3AD MOMENTS AFTER BEING RELEASED FROM PRISON
        │
        ├─ 🇰🇷  출소 직후 총격 사망 / 그를 기다린 건 자유가 아니었다   (감성적 반전)
        └─ 🇯🇵  出所から24時間で射殺 / 法に代わる「復讐」の正義        (사회적 논쟁)
```

원문에 없는 문장을 만들어낸다. 같은 사건이라도 문화별로 후킹 포인트를 다르게 잡는다.

자세한 근거와 설계는 [docs/SPEC.md](docs/SPEC.md) 참고.
