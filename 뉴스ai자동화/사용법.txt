===========================================
   뉴스 AI 자동화  ·  5차 (음성 들어옴)
===========================================

쓰는 법
--------
    시작.bat  을 두 번 누른다.

검은 창이 하나 뜨고, 이어서 크롬 창이 저절로 열린다.
※ 검은 창은 닫지 마. 그게 꺼지면 화면도 멈춘다.

파이썬이 없으면 검은 창이 받는 곳을 알려준다.
깔 때 "Add python.exe to PATH" 에 반드시 체크할 것.


이번에 새로 된 것 — 2단계 음성
--------------------------------
남자·여자 목소리를 고르고, 말 속도를 0.8~1.5배로 맞춰서
대본 전체를 소리로 만든다.

그리고 이게 중요한데,
문장마다 **실제로 몇 초인지 재서** 들고 있는다.
그 길이로 4단계 스토리보드가 컷을 나눈다.

    음성 먼저  →  실제 길이로 컷을 나눔  →  그림과 말이 안 어긋남
    음성 없이  →  글자 수로 어림짐작      →  조금씩 밀림

그래서 순서는 **음성이 먼저, 컷 나누기가 나중**이다.
(음성 없이 스토리보드로 가도 되긴 하는데, 화면이 노란 글씨로
 "어림잡아 나눴다" 고 알려준다)


목소리는 두 곳 중에 고른다 — 둘 다 돈 안 듦
----------------------------------------------

  윈도우 내장     가입도 열쇠도 카드도 필요 없다. 인터넷도 안 쓴다.
                  바로 [목소리 불러오기] 누르면 네 컴퓨터에 깔린
                  목소리가 쭉 뜬다.
                  단점 : 소리가 좀 딱딱하다.

                  ※ 한국어 목소리가 하나도 안 보이면
                    윈도우 설정 → 시간 및 언어 → 음성 →
                    음성 추가 → 한국어 를 깔면 된다.

  구글 Cloud      월 400만 자까지 공짜. 상업 이용 허락돼 있다.
                  대본 한 편이 4,500자쯤이니 **한 달에 890편까지 공짜**다.
                  훨씬 사람 목소리 같다.

                  열쇠 받는 법 :
                    console.cloud.google.com 접속
                    → 프로젝트 만들기
                    → "Text-to-Speech API" 검색해서 사용 설정
                    → 사용자 인증 정보 → API 키 만들기
                    → AIza... 로 시작하는 글자를 복사해서 칸에 붙여넣기

                  ※ 카드 등록을 요구할 수 있다. 400만 자를 안 넘으면
                    청구되지 않지만, 넘으면 돈이 나간다. 이건 네가 판단해라.
                    불안하면 윈도우 내장으로 써도 영상은 나온다.

목소리 목록은 내가 적어 둔 게 아니라, 프로그램이 그때그때
직접 물어서 가져온다. 그래서 목록이 틀릴 일이 없다.


흐름 — 한 줄로 간다
--------------------

   1. 대본        기사 주소 넣고 → 클로드가 써 줌
   2. 음성        목소리·속도 고르고 → 소리 만들기        ← 이번에 됨
   3. 스타일      화풍 12가지 중 하나
   4. 스토리보드  실제 음성 길이로 12~13초씩 컷 나누기
   5. 이미지      컷마다 영문 프롬프트
   6. 영상        전부 붙여서 mp4                          (다음 차례)
   7. 완성        내보내기                                 (다음 차례)

왼쪽 기둥이 순서를 끌고 간다.


핵심 구조
----------

   대본
     └ 문장마다 소리로 만들고 길이를 잼
            │
            └ 그 길이로 12~13초씩 묶음  →  컷
                   │
                   컷 하나 = 대본 토막 하나
                   │
                   ├ 그 토막이 그대로 자막이 된다
                   ├ 그 토막을 읽고 장면을 묘사한다
                   ├ 묘사 + 화풍 → 영문 이미지 프롬프트
                   └ 그림 한 장

   한 컷 = 대본 토막 = 그림 한 장 = 자막 한 구간

문장 중간에서는 절대 자르지 않는다.
자르면 자막이 깨지고 그림이 글과 안 맞는다.


숫자의 근거 (레퍼런스 영상 실측)
---------------------------------

   대본 4,621자  →  9분  →  43컷 (한 컷 13초)

   즉   1분 = 약 513자
        1컷 = 약 107자 = 13초 = 그림 1장

   분량별 필요한 그림 장수
       9분   4,600자    43장
      20분  10,300자    92장
      30분  15,400자   138장
      60분  30,800자   277장


음성 만드는 데 얼마나 걸리나
------------------------------
4,500자 대본이면 문장이 130개쯤 된다.
문장 하나에 1~2초씩 걸리니까 **3~5분**이다.
진행 막대가 "문장 57/130 만드는 중" 처럼 알려준다.

다 되면 전체가 몇 분짜리인지 알려주고,
그대로 [스토리보드로 →] 를 누르면 된다.

아직 안 되는 것 — 솔직하게
----------------------------
  6단계 영상 조립   아직. 이게 제일 큰 숙제다.
  7단계 완성        아직.

  그리고 내가 확인 못 한 것 :
  나는 리눅스 서버에서 일하고 있어서 **윈도우 목소리도,
  구글 목소리도 여기서는 못 돌려 봤다.**
  화면이 제대로 그려지는 것, 속도가 저장되는 것, 성별로 걸러지는 것,
  실제 길이로 컷이 나뉘는 것까지는 전부 돌려서 확인했다.
  하지만 소리가 진짜로 나오는지는 네 컴퓨터에서 눌러 봐야 안다.

  안 되면 화면에 뜨는 빨간 글씨를 그대로 나한테 보내줘. 바로 고친다.
